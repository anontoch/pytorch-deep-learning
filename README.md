# pytorch-deep-learning

PyTorch practice scripts with clear file names.

| File | Topic |
|---|---|
| `advertising_wechat_regression.py` | Single-feature linear regression |
| `advertising_multi_feature_regression.py` | Multi-channel advertising regression |
| `iris_pytorch_models.py` | Iris logistic regression + neural net |
| `titanic_logistic_regression.py` | Titanic binary classifier |
| `tensor_dimensions_demo.py` | Tensor shape examples |

## Data

CSV files live in `data/` (`advertising.csv`, `train.csv`, `iris.csv`).

## Run

```powershell
pip install torch pandas numpy matplotlib scikit-learn
python advertising_wechat_regression.py
```
